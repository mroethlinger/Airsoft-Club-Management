# Airsoft Club Management

A standalone WordPress plugin for airsoft clubs: public website, member area (PWA), club management (members, squads, regions, events, carpools, applicants, gear, leadership tools) and the association's books (fees, cash book, donation receipts).

Status: **in development** (phases 0–1 done, phase 2 in progress, not ready for production). See [docs/PLAN.md](docs/PLAN.md) for scope, architecture and phases, [CHANGELOG.md](CHANGELOG.md) for progress and [docs/TESTING.md](docs/TESTING.md) for tests.

- Runs on ordinary shared hosting (no SSH, Composer, Node.js or cron needed on the server).
- Updates through the WordPress plugin updater.
- German user interface, English code and documentation.
